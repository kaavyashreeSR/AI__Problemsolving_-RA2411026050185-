# Interactive Tic-Tac-Toe AI

## Description
A complete command-line Tic-Tac-Toe game written in Python, featuring an AI opponent. The AI uses the Minimax algorithm for "hard" mode, making it unbeatable. It also offers an "easy" mode that plays randomly.

## Features
- **Board Logic**: Win/draw detection and board display.
- **Minimax Algorithm**: An unbeatable AI opponent.
- **Difficulty Levels**: Choose between Easy (random moves) and Hard (Minimax).
- **Interactive CLI**: Choose your player (X or O) and play directly in the terminal.

## Requirements
- Python 3.x

## How to Run
1. Clone the repository.
2. Navigate to the `TicTacToe/` directory.
3. Run `python main.py`.
4. Follow the on-screen prompts to play.
